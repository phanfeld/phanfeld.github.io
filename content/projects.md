## Projects, Software & OER

* **[VÖBBRadar](https://github.com/phanfeld/voebbradar)**: A Terminal User Interface (TUI)-based search app built to comfortably query and navigate the VÖBB (Verbund der Öffentlichen Bibliotheken Berlins) library database directly from the command line.
* **[Jugend hackt AI Demonstrators](https://github.com/Jugendhackt/AIDemonstrators)**: A collection of educational open-source AI demonstrators, featuring projects such as face recognition, style transfer, and a Reinforcement Learning agent trained to play Pong. 
* **Game Development with Unity (OER)**: A comprehensive two-part tutorial series for building a simple game in Unity using visual scripting. Published as an Open Educational Resource (OER) for *Jugend hackt*.
  * [Part 1: Setup and Basics](https://jugendhackt.org/oer/projekte/game-development-unity-1/)
  * [Part 2: Gameplay and Logic](https://jugendhackt.org/oer/projekte/game-development-unity-2/)
